#  AI Video Assistant

An AI-powered Video & Meeting Assistant that can:

- 🎙️ Transcribe audio/video content
- 📝 Generate smart summaries
- 📌 Extract action items
- 🔑 Detect key decisions
- ❓ Identify open questions
- 💬 Chat with your meeting/video using RAG (Retrieval-Augmented Generation)

Supports:
- YouTube videos
- Local audio/video files
- English & Hinglish transcription

---

# 🚀 Features

## ✅ Smart Transcription
Automatically converts audio/video into text.

## ✅ AI Summary Generation
Creates concise meeting/video summaries.

## ✅ Action Item Extraction
Detects tasks and responsibilities from conversations.

## ✅ Key Decision Detection
Extracts important decisions made during discussions.

## ✅ Open Question Detection
Finds unanswered questions from meetings.

## ✅ RAG-based Chat Assistant
Ask questions about the uploaded meeting/video.

Example:
```bash
You: What was the final decision?
Assistant: The team decided to launch the beta version next Friday.
